# 检索策略与运行说明

当前版本：2026-11-07-coverage-v1。

## 收录范围

- A：高影响力期刊，包括 NEJM、Lancet、JAMA、BMJ 四本主刊。
- B1/B2：癫痫专科与神经科学期刊。
- A/B1/B2 主题：`epilep* OR seizure*`（题名/摘要/作者关键词）并联 Epilepsy、Seizures、Status Epilepticus 的 MeSH。
- C：脑电信号与分析方法；D：闭环神经调控，保持既有检索。
- E：神经过度兴奋、兴奋抑制平衡与建模/推断/补偿机制。该组允许没有癫痫词的邻近研究，范围限于配置中的神经科学和计算期刊。

不按 Editorial、Letter 或没有摘要排除文献。PubMed 原始发表形式会保留在日报和新增飞书记录的“发表形式（自动）”；它不能直接代表研究设计。Journal Article 也不会自动被认定为原始实验研究。PubMed 有关联条目时保留关系及 PMID；没有关系时不猜测述评对应的原始研究。

自动相关度只给“推荐/浏览”，不再自动标“必读”。已存在记录的优先级、已读状态和人工文献类型保持不变。研究价值仍需要结合科学问题与使用目的判断。

## 每日与每周

每日仍按北京时间05:00计划触发，GitHub 实际启动可能延迟。每组通常覆盖截至昨天的3天EDAT，按PMID完整查重。若相同查询上次覆盖落后，则从最后成功位置重叠恢复，每轮最多补7天，报告记录每组实际日期。

每周日北京时间05:30另行检索过去7天不限期刊的主题候选，生成可在GitHub直接阅读的 [候选清单](../reports/weekly_candidates.md)、HTML和JSON。包含近期更新的图书章节时单独标明章节和更新日期。该模式不翻译、不调用飞书/Notion写入、不推进每日进度；候选供进一步筛选。它仍是 PubMed 范围内的提醒，不能替代多数据库系统综述。

## 完整性与恢复

- 搜索ID分页获取，每页最多100，配置上限500。超出上限、请求失败、重复页、计数变化或详情缺失都会显示未完整，任务失败，不推进对应组进度。
- 详情按20篇批量获取；无原始摘要与详情请求失败分开处理。
- 仅检索完整、且飞书同步经读回核验成功的组推进 `reports/search_progress.json`。
- 发布检索式变化后默认从3天窗口开始，避免突然大量补历史；历史查漏通过明确的组及日期完成。
- 代表性文章检查不限制日期：A必须找回两篇Neurology述评、eLife过度兴奋建模、NEJM化学遗传学来信；E必须找到eLife建模。每天运行时反查，发现后续改动损坏覆盖即告警。通过这些案例不等于证明全领域召回率。

## 手工补抓

Actions 选择 `backfill`，填写 `groups`（例如A）、`edat_start`、`edat_end`，日期均为PubMed入库日。或者：

```text
python scripts/run_daily.py --groups A --edat-start 2026-10-07 --edat-end 2026-11-06
```

两个日期必须同时提供，结束日不能超过报告日期前一天。补抓与每日模式共用持久队列和完整查重，只新增不存在的PMID；已读/优先级等原有信息不被覆盖。翻译先用标题缓存，标题缺失保留待重试，原文没有摘要时不生成摘要。

## 下一轮迭代

保留“直接相关”“方法可迁移”“当前不感兴趣”等实际阅读反馈，观察有代表性的正例与负例，再调整查询和排序。只根据三篇正例不能测定查全率或查准率。课程统计方法学习应使用另外的证据标签和精读笔记，避免由摘要词匹配自动断定已理解某方法。
